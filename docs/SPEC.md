# 组件合同

## 文档

`CodeDocument(text)` 保存原始 UTF-8 字节。空文档有一行。LF、CRLF 和单 CR 分隔逻辑行，尾部换行产生空行。`version` 从零开始。所有位置和范围使用零起点，范围右端不包含在内。

`read(Utf8Range)` 只复制请求的正文。`lineRange(line, includeBreak)` 默认返回行内容，传入 true 时包括该行分隔符。`positionAt(offset)` 和 `offsetAt(CodePosition(line, column))` 在文档字节和行内字节列之间转换。CRLF 中间位置折合到前一行末。越界或切开 UTF-8 标量的请求抛出 IllegalArgumentException。

`snapshot()` 固定当前版本并封存追加块。不可变红黑树允许快照共享当时的根和片段描述，取得快照的耗时与文档长度无关。快照保留相同的读取与定位能力，`forEachChunk` 按正文顺序交付独立的字符串片段，允许调用方在遍历中修改实时文档。

## 编辑与选区

`CodeEdit` 的范围以旧正文为准。`applyEdits` 针对期望版本原子提交。结果为 Applied、Unchanged、Stale、Invalid、ReadOnly 或 Busy。通知或计算选区时重入同一文档返回 Busy。相邻非空替换合法；同起点或相交的替换无效。等值替换只提供结果范围，不改变正文、历史和内部位置。

`CodeEditorState(document)` 拥有有方向和视觉偏向的选区。相交范围合并，重复光标去重，落在非空范围端点的光标归入该范围。主身份跟随所属组，两个非空范围相接时共同端点的空主光标归入右组。`executeEdits` 的可选同步回调按输入顺序查询新范围并返回最终选区。回调异常或最终选区无效时整批失败。被动光标跟到插入内容之后，非空选区默认排除边缘插入。

同一文档的所有视图先完成映射，再通知观察者。`onChange` 和 `onSelectionChange` 返回可重复关闭的登记。撤销和重做共享一条文档历史，发起操作的可写视图恢复交互命令记录的选区。连续、同视图、同方向的键入或删除可合并。粘贴、组合提交、移动选区和焦点变化划分历史边界。

## 导航与文字命令

左右移动及同方向删除使用扩展字素边界，CRLF 作为一个换行。Enter 沿用所在行的行尾，末行取上一行，没有参考行时用 LF。多行缩进对逻辑行去重，移除缩进时最多删除一个 Tab 或一个制表位的空格。复制多个选区时以 LF 连接各段原始正文。

显示时 Tab 展开到下一个制表位，默认宽度为四列。普通字素按其中最宽字符计列，至少一列。点击展开的一段空格时选择较近的 Tab 端点。文档内始终保存原始 Tab。

### 多选区剪贴板

所有选区均为空时按逻辑行复制／剪切，同一行的多个光标共用一个片段。最后一行没有换行时，复制的行片段补上局部换行。向空光标粘贴整行时插在所在行之前，原来的阅读列随正文移动。系统剪贴板同时发布普通文本和保留各段原始字节的文本表示。分段模式按选区数量匹配分发，完整模式向每处粘贴全部内容。外部纯文本也可按行分发。一次剪切或粘贴可整笔撤销。

### 行块、缩进与行尾

行命令按逻辑行工作，非空选区恰好结束在下一行行首时只包含前面的行。相邻的选中行在移动、复制和删除时合并为一块。移动后保留选区方向及所在内容，复制行时选中副本。向上／下插入行继承缩进，合并行去掉后一行的缩进并按需插入一个空格。显式转换整篇行尾、转换缩进以及各项行命令均形成独立撤销项。视图通过 `canUndo` 与 `canRedo` 查询可执行状态。

`tabSize` 决定字面 Tab 的显示列宽，`indentSize` 决定一级缩进的列数。按 Tab 可写入制表符或到下一制表位的空格。Enter 沿用当前行行尾并继承插入位置之前的前导缩进。退格在空格缩进内回到上一个缩进位。

## 原生输入

每次连接只发布主选区覆盖的完整逻辑行，首尾两行之间保留原始换行。平台看到片段内的 UTF-8 方向选区，编辑器保存片段的文档起点。同一批原生操作按顺序解释，每步坐标均属于前一步所得片段。普通 CurrentSelection 键入替换所有选区；显式范围、删除周边及组合输入只操作主选区。

组合串属于活动视图，可以包含换行。更新 preedit 保留原文档版本、其他视图及历史；空 preedit 恢复开始组合时的选区。Commit 或接受非空标记的 ClearPreedit 只提交一次。若一批既提交旧组合又开始新组合，只发布已经提交的部分。外部修改或主选区移动使旧投影失效。原生批次先按原坐标确认，再按需独立发布新的行片段；即使两行文字相同，坐标起点改变也推进输入 revision。

## 语言配置与键入

同一文档的视图共享可选的 `CodeLanguage`。宿主可声明词的正则、行／块注释符、配对符、可自动闭合的符号、可包围选区的符号以及回车缩进规则。`scoopCodeLanguage()` 提供 Scoop 源码的默认规则。切换配置会清除各视图对旧闭合符的追踪。

`typeText` 和原生普通键入逐一处理所有选区，并将修改合并为一次事务。输入开放符可插入一对字符并将光标置于中间。可跳过本视图生成并仍存在的闭合符，空配对中退格会删除整对。输入包围符时保留原选区内容和方向。粘贴、显式范围替换和输入法提交组合串按原文写入。

回车规则取得选区开始位置之前和结束位置之后的逻辑行文本，决定沿用、增加、减少一级缩进，或将配对符分到两行并在中间增加一级缩进。换行沿用局部行尾。`comment.line` 按去重后的逻辑行切换注释，`comment.block` 添加或移除选区两端的标记。每次操作均可整笔撤销。词导航、双击选词和从当前词开始选取匹配共同消费配置的词边界。

## 文档内查找

每个视图按需创建一份 `CodeFind`。`find.open` 从非空主选区取值，`selection.addNextMatch` 可从光标所在的词开始。查找支持双向循环、选择全部、跳过当前匹配、大小写、Unicode 全词、正则及选区内查找。选区搜索范围在启用时固定，之后随文档编辑映射。零长度正则结果可以向前或向后遍历。无效模式在面板显示错误并清空旧结果。替换支持编号和命名捕获组及字面美元符，整批替换共用一个撤销项。

## 动作与键位

`listActions()` 返回稳定 ID、标签、当前快捷键和可用状态，`canRunAction(id)` 供菜单查询，`setActionShortcut(id, chord)` 更换或移除单个默认键位。同一视图的快捷键唯一。原生编辑选择器、菜单和宿主调用共用对应的动作。输入法组合期间，取消组合优先于普通快捷键。Esc 依次清除次光标、收起主选区。Tab 可切换为焦点遍历。

### 列选、多光标与阅读位置

Alt 点击可追加光标，Alt+Shift 拖动在视觉行上形成矩形选区。键盘可以扩展矩形的四条方向、在上方／下方加光标、在选中各逻辑行的行尾加光标，或逐次扩选整行。列选择用行布局实测的像素横坐标命中 Tab、宽字、短行与折行，结果仍是通常的有方向选区。双击后按词拖选，三击或从行号栏开始按整行拖选。拖出视口时持续滚动，释放或失焦停止。

滚动条使用所在应用的主题。滚动动作支持按行、按页及居中显示光标。单独滚动保留选区。转到行列面板使用从一开始的行号和 Unicode 标量列，宿主的 `goTo(CodePosition)` 使用零起点 UTF-8 字节列。`saveViewState` 保存选区方向、主光标和阅读锚点，`restoreViewState` 在可用范围内恢复，文档缩短时收回到有效边界。

## 自绘视口

`codeEditor(state)` 返回可嵌入布局的 View。每个 state 同时只挂载一次，拥有独立的阅读位置、软换行与配色设置。排版读取可见逻辑行及相邻行，行号栏固定，同一 TextLayout 负责绘制、命中、双向选区、视觉移动和 caret。选择变化和光标闪烁可以复用行布局。只有与当前文档、输入投影及选项匹配的 Accepted 帧提供可见范围和窗口逻辑坐标中的 caret 矩形。宿主提供的选区端点可以位于字素内部的标量边界，显示 caret 时依视觉偏向落到相邻的字素边缘。

获得焦点的 InputArea 自行发布局部文本并消费原生批次。候选窗使用已接受且与输入 revision 匹配的 caret。多行 TextField 辅助语义提供完整正文、全文方向选区以及通过编辑事务执行的辅助编辑。系统剪贴板复制原始选区字节。

## 扩展

### 折叠与可见行

折叠范围使用零起点的逻辑行，首尾均包含。宿主可按文档版本调用 `setFoldingRanges` 提交嵌套范围，清空后恢复按缩进推导。每个视图通过 `folding` 拥有自己的手动范围和已折叠范围。编辑前后追踪范围两端，范围缩短到一行即消失。保存视图状态时一并保存手动范围和折叠状态。

折叠保留首行，在该行末显示可点击的省略号。点边栏箭头或执行命令可折叠／展开当前层、递归处理子层或处理全部范围。主修饰键与 Alt 加左右方括号调整当前范围，再加 Shift 递归操作。主修饰键与 Alt 加 0 或 9 折叠或展开全部范围。手动范围优先，新的手动范围取代与它交叉的旧手动范围。隐藏正文继续参加文档读取、复制、着色与查找。导航、矩形列选、控件和滚动按可见行排版，查找与显式跳转会展开目标所在的折叠层。两个视图可呈现不同的行，视口事件按段报告真正可见的源码范围。

### 逐行着色与主题

`CodeLanguage.tokenizer` 可接入宿主的 `CodeTokenizer`。着色器从不可变的初始状态开始，按逻辑行返回 UTF-8 字节区间、类别名及下一行的入口状态。区间按源码顺序排列，彼此不重叠。文档共享行结果。编辑使涉及的行失效，后续行的入口状态与已有结果相同时复用剩余区间。主题和视图装饰独立叠加，均不进入正文或撤销栈。

`scoopCodeLanguage()` 包含识别关键词、数值、字符串、行注释及嵌套块注释的着色器，三引号字符串和块注释可跨行。宿主用 `CodeEditorOptions(theme = ...)` 选择浅色、深色、高对比或自定义主题，同一文档的两个视图可使用不同配色。

### 范围装饰与控件

`CodeDecorationStyle.font` 接受 Scoop Graphics 的 `SpanStyle`，可按范围改变字体族与回退、字号、字重、字形倾斜等。文档样式、视图样式按登记顺序逐属性叠加。范围前景覆盖同一装饰的字体颜色。可见行与离屏导航使用同一套文本排版，折行、点击、选区及输入法候选位置读取相同的字形几何。改变字形度量时按阅读锚点更新行高。背景、下划线和边栏标记变化只触发重绘。

文档与视图均可创建 `decorations()` 集合，设置范围的前景、背景、下划线及行号标记，并为每个端点指定插入黏附。绘制先用文档样式，再用视图样式，同一属性按登记及设置顺序覆盖。集合随事务映射，可单独清空、关闭。批量设置无效范围时保留原集合。

`addAction` 通过 id、标签、可选快捷键、启用谓词与执行函数登记动作。`runAction` 与焦点路由中的快捷键共用启用判断。内容控件锚定文档位置，浮层固定视口角落，行间控件按实际高度占位。各自返回可关闭的登记。编辑使锚点映射到新正文，离屏的内容控件从本帧布局和命中中移除。

`CodeFind(editor)` 与按需获取的 `editor.find` 共用一份视图内搜索。默认字面查找区分大小写并流式扫描快照的各个片段。空查询清除本视图高亮，关闭面板恢复正文焦点。`CodeLineNote` 使用行号标记、位置提示及行间控件展示可展开的批注。

### 行前、行后空间与 CodeLens

`addViewZone(line, side, view)` 按源码逻辑行锚定控件。行前控件位于该行第一条视觉行上方，行后控件位于最后一条视觉行下方。同一侧按登记顺序排列，第一行上方也能占位。控件内容或字体改变时按实测高度重新排版，宿主可调用 `remeasureWidgets()` 主动请求测量。折叠隐藏行上的控件随该行隐藏。`hitTest(windowPoint)` 从已呈现帧区别正文位置、边栏、折叠控件、内容控件、浮层及行间控件。

宿主通过 `editor.codeLenses()` 为当前视图登记一组 Lens，按快照版本整体替换，可单独关闭。每项有源码范围和动作，也可先给标签，再在按钮实际进入视口时使用当前快照解析动作。同一源码行的各组动作共用一行原生按钮。编辑重定位锚点，分行或并行会重新归组。按键或点击都可执行，Escape 返回正文。过期结果和已关闭登记不再更新视图。
