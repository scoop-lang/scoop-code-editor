# 组件合同

## 文档

`CodeDocument(text)` 保存原始 UTF-8 字节。空文档有一行。LF、CRLF 和单 CR 分隔逻辑行，尾部换行产生空行。`version` 从零开始。所有位置和范围使用零起点，范围右端不包含在内。

`read(Utf8Range)` 只复制请求的正文。`lineRange(line, includeBreak)` 默认返回行内容，传入 true 时包括该行分隔符。`positionAt(offset)` 和 `offsetAt(CodePosition(line, column))` 在文档字节和行内字节列之间转换。CRLF 中间位置折合到前一行末。越界或切开 UTF-8 标量的请求抛出 IllegalArgumentException。

`snapshot()` 固定当前版本并封存追加块。不可变红黑树允许快照共享当时的根和片段描述，取得快照的耗时与文档长度无关。快照保留相同的读取与定位能力，`forEachChunk` 按正文顺序交付独立的字符串片段，允许调用方在遍历中修改实时文档。

## 编辑与选区

`CodeEdit` 的范围以旧正文为准。`applyEdits` 针对期望版本原子提交。结果为 Applied、Unchanged、Stale、Invalid、ReadOnly 或 Busy。通知或计算选区时重入同一文档返回 Busy。相邻非空替换合法；同起点或相交的替换无效。等值替换只提供结果范围，不改变正文、历史和内部位置。

`CodeEditorState(document)` 拥有有方向和视觉偏向的选区。相交范围合并，重复光标去重，落在非空范围端点的光标归入该范围。主身份跟随所属组，两个非空范围相接时共同端点的空主光标归入右组。`executeEdits` 的可选同步回调按输入顺序查询新范围并返回最终选区。回调异常或最终选区无效时整批失败。被动光标跟到插入内容之后，非空选区默认排除边缘插入。

同一文档的所有视图先完成映射，再通知观察者。`onChange` 和 `onSelectionChange` 返回可重复关闭的登记。撤销和重做共享一条文档历史，发起操作的可写视图恢复交互命令记录的选区。连续、同视图、同方向的键入或删除可合并。粘贴、组合提交、移动选区和焦点变化划分历史边界。

## 导航与文字命令

左右移动及同方向删除使用扩展字素边界，CRLF 作为一个换行。Enter 沿用所在行的行尾，末行取上一行，没有参考行时用 LF。多行缩进对逻辑行去重，移除缩进时最多删除一个 Tab 或一个制表位的空格。复制多个选区时以 LF 连接各段原始正文。

显示时 Tab 展开到下一个制表位，默认宽度为四列。普通字素按其中最宽字符计列，至少一列。点击展开的一段空格时选择较近的 Tab 端点。文档内始终保存原始 Tab。

## 原生输入

每次连接只发布主选区覆盖的完整逻辑行，首尾两行之间保留原始换行。平台看到片段内的 UTF-8 方向选区，编辑器保存片段的文档起点。同一批原生操作按顺序解释，每步坐标均属于前一步所得片段。普通 CurrentSelection 键入替换所有选区；显式范围、删除周边及组合输入只操作主选区。

组合串属于活动视图，可以包含换行。更新 preedit 保留原文档版本、其他视图及历史；空 preedit 恢复开始组合时的选区。Commit 或接受非空标记的 ClearPreedit 只提交一次。若一批既提交旧组合又开始新组合，只发布已经提交的部分。外部修改或主选区移动使旧投影失效。原生批次先按原坐标确认，再按需独立发布新的行片段；即使两行文字相同，坐标起点改变也推进输入 revision。

## 自绘视口

`codeEditor(state)` 返回可嵌入布局的 View。每个 state 同时只挂载一次，拥有独立的阅读位置、软换行与配色设置。排版读取可见逻辑行及相邻行，行号栏固定，同一 TextLayout 负责绘制、命中、双向选区、视觉移动和 caret。选择变化和光标闪烁可以复用行布局。只有与当前文档、输入投影及选项匹配的 Accepted 帧提供可见范围和窗口逻辑坐标中的 caret 矩形。宿主提供的选区端点可以位于字素内部的标量边界，显示 caret 时依视觉偏向落到相邻的字素边缘。

获得焦点的 InputArea 自行发布局部文本并消费原生批次。候选窗使用已接受且与输入 revision 匹配的 caret。多行 TextField 辅助语义提供完整正文、全文方向选区以及通过编辑事务执行的辅助编辑。系统剪贴板复制原始选区字节。

## 扩展

文档与视图均可创建 `decorations()` 集合，设置范围的前景、背景、下划线及行号标记，并为每个端点指定插入黏附。绘制先用文档样式，再用视图样式，同一属性按登记及设置顺序覆盖。集合随事务映射，可单独清空、关闭。批量设置无效范围时保留原集合。

`addAction` 通过 id、标签、可选快捷键、启用谓词与执行函数登记动作。`runAction` 与焦点路由中的快捷键共用启用判断。内容控件锚定文档位置，浮层固定视口角落，行间控件按实际高度占位。各自返回可关闭的登记。编辑使锚点映射到新正文，离屏的内容控件从本帧布局和命中中移除。

`CodeFind(editor)` 提供字面串查找、当前替换、选择下一个匹配及批量替换，可打开视图角落的查找面板。空查询清除本视图高亮，大小写敏感、按文档顺序返回非重叠匹配。查找使用固定快照、跨片段匹配和提交版本校验。关闭面板恢复正文焦点。`CodeLineNote` 使用行号标记、位置提示及行间控件展示可展开的批注。
